# Backrooms Caution Tape

NeoForge mod for Minecraft 1.21.1.

## Build on GitHub

1. Create a GitHub repository and upload the contents of this folder.
2. Open the repository's **Actions** tab. The build runs on pushes and pull requests; select **Build mod** and choose **Run workflow** to start one manually.
3. Open a completed workflow run and download the `backrooms-tape` artifact. It contains the mod JAR.

The build uses Java 21 and NeoForge 21.1.265.
